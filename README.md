# 🏠 مراقبت از خانه — House Tracker

وب‌اپ ساده برای ثبت رفت‌وآمد و کارهای خانه وقتی صاحب‌خانه نیست.

تمام برنامه در یک فایل است: `index.html` — بدون سرور، بدون نصب، بدون اینترنت.
کافی است فایل را در مرورگر باز کنی (یا روی GitHub Pages بگذاری).

## استفاده

1. فایل `index.html` را در مرورگر باز کن (موبایل یا کامپیوتر).
2. **ورود**: اسمت را انتخاب کن و «چک‌این» بزن — ساعت، روز و تاریخ (میلادی) ثبت می‌شود.
3. **کارها**:
   - اول بنر بالای صفحه: **«وقتی وارد می‌شوید آب را به home تغییر دهید»**.
     تا وقتی این را تأیید نکنی، ثبت هیچ کار مثبتی فعال نمی‌شود.
   - **کارهای خانه** (اختیاری، `P1`…`P9`): هر کاری که انجام دادی را بزن → **+۱**.
     دوباره زدن، ثبتِ همان روز را برمی‌دارد.
   - **قبل از رفتن** (اجباری، `N1`…`N7`): امتیاز مثبت ندارد.
     اگر کسی انجام نداده، هر کسی می‌تواند برایش **−۱** ثبت کند:
     اول شخص خاطی را از لیست انتخاب کن، بعد روی آن کار بزن.
4. **امتیازها**: تعداد مثبت و منفی هر نفر **جداگانه** (جمع/تفریق نمی‌شوند)، با فیلتر بازهٔ زمانی.
   با کلیک روی نام هر کس، کل تاریخچه‌اش با تاریخ باز می‌شود.
5. **تاریخچه**: همهٔ ثبت‌ها با فیلتر شخص/نوع؛ هر ثبت قابل **ویرایش** (شخص، نوع، کار، تاریخ و ساعت، توضیح) و **حذف** است.
6. **تنظیمات**: افزودن/حذف/تغییر نام افراد، ویرایش متن و کد کارها، پشتیبان‌گیری و پاک‌سازی.

## خروجی اکسل

دکمهٔ «خروجی اکسل» (بالای تبِ تاریخچه و در تنظیمات) یک فایل `.xlsx` با سه برگه می‌سازد:

| برگه | ستون‌ها |
|---|---|
| تاریخچه | ردیف، تاریخ میلادی، ساعت، روز هفته، نام، نوع، کد کار، عنوان کار، توضیح کار، امتیاز مثبت، امتیاز منفی، یادداشت، ثبت‌کننده، شناسهٔ ثبت |
| امتیازها | نام، مثبت، منفی، تعداد ورود، آخرین ورود، آخرین فعالیت |
| کارها | کد، نوع، عنوان، توضیح کامل |

ستون‌های امتیاز عددی هستند تا در اکسل قابل جمع‌زدن و Pivot باشند، و برگه‌ها راست‌به‌چپ با سطر عنوان ثابت باز می‌شوند.
فایل بدون هیچ کتابخانه‌ای ساخته می‌شود (نوشتن مستقیم ZIP + SpreadsheetML)، پس آفلاین هم کار می‌کند.
اگر محیط اجازهٔ ذخیرهٔ `xlsx` ندهد، خودکار سراغ `csv` و در نهایت متن قابل‌کپی (Tab-separated) می‌رود.

## ظاهر

تم کاغذ کرم با جوهر قهوه‌ای؛ فونت‌ها **وزیرمتن** (متن) و **لاله‌زار** (تیترها) به‌صورت data-URI داخل خود فایل جاسازی شده‌اند،
پس بدون اینترنت و بدون CDN هم دقیقاً همین‌طور نمایش داده می‌شود. هر کار شکلک مخصوص خودش را دارد که از تنظیمات قابل تغییر است.

## کدها

برای اینکه لیست‌ها شلوغ نشوند، هر کار یک کد کوتاه دارد (`P1`, `N3`, `HOME`) و عنوانش خلاصه است.
با زدن ⓘ کنار هر کار، توضیح کامل باز می‌شود. کد و عنوان هر دو از بخش «تنظیمات» قابل ویرایش‌اند.

## پشتیبان و پاک کردن حافظه

- **دانلود فایل پشتیبان**: هر وقت بخواهی یک فایل JSON از کل اطلاعات می‌گیری.
- **بازیابی از فایل**: همان JSON را برمی‌گرداند.
- **پاک کردن ثبت‌ها** یا **ریست کامل**: پیش از حذف، فایل پشتیبان **به‌صورت خودکار دانلود می‌شود** و بعد حافظه پاک می‌گردد.

## همگام‌سازی بین گوشی‌ها

به‌صورت پیش‌فرض اطلاعات در `localStorage` **همان مرورگر و همان دستگاه** می‌ماند.
برای اینکه هر سه نفر از گوشی خودشان روی **یک لیست مشترک** ثبت کنند، اپ به یک Google Sheet وصل می‌شود:

- بک‌اند یک Google Apps Script است که روی شیت خودت اجرا می‌شود ([`google-apps-script/Code.gs`](google-apps-script/Code.gs)) — سرور واسطی در کار نیست.
- راه‌اندازی گام‌به‌گام: [**SETUP-SYNC.md**](SETUP-SYNC.md)
- ثبت‌ها اول محلی ذخیره می‌شوند، بعد در پس‌زمینه بالا می‌روند؛ **آفلاین هم کار می‌کند** و بعد از وصل شدن خودش می‌فرستد.
- هر سطر یک `rev` سمت سرور می‌گیرد، پس ساعت اشتباهِ یک گوشی چیزی را خراب نمی‌کند؛ حذف‌ها هم به شکل tombstone منتقل می‌شوند و برنمی‌گردند.
- با «کپی لینک آماده برای بقیه»، گوشی بقیه با یک کلیک تنظیم می‌شود.

همگام‌سازی روی لینک claude.ai کار نمی‌کند (آن صفحه اجازهٔ اتصال بیرونی ندارد و خودش تذکر می‌دهد)؛ از لینک GitHub Pages استفاده کنید.

## انتشار روی GitHub Pages

از `Settings → Pages` شاخه را روی همین برنچ و پوشهٔ `/ (root)` بگذار؛
آدرس ساخته‌شده روی گوشی هم باز می‌شود و می‌توانی به صفحهٔ خانه اضافه‌اش کنی.
