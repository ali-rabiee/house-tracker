# 🏠 مراقبت از خانه — House Tracker

وب‌اپ ساده برای ثبت رفت‌وآمد و کارهای خانه وقتی صاحب‌خانه نیست.

تمام برنامه در یک فایل است: `index.html` — بدون سرور، بدون نصب، بدون اینترنت.
کافی است فایل را در مرورگر باز کنی (یا روی GitHub Pages بگذاری).

## استفاده

1. **ورود**: اسمت را انتخاب کن و «چک‌این» بزن — ساعت، روز و تاریخ (میلادی) ثبت می‌شود.
   نوبت تا زمان چک‌اوت باز می‌ماند، حتی چند روز؛ برای ثبت کار لازم نیست دوباره چک‌این کنی.
2. **کارها**:
   - اول بنر بالای صفحه: **«وقتی وارد می‌شوید آب را به home تغییر دهید»**. با زدنش یک تأییدیه می‌پرسد؛
     تا تأیید نکنی، ثبت هیچ کار مثبتی فعال نمی‌شود. این تأیید روزانه است و به چک‌این وابسته نیست.
     همهٔ پرسش‌های اپ داخل خودِ صفحه رسم می‌شوند، چون میزبان‌های سندباکس‌شده `confirm()` مرورگر را نادیده می‌گیرند.
   - **کارهای خانه** (اختیاری، `P1`…`P9`): هر کاری که انجام دادی را بزن → **+۱**. دوباره زدن، ثبتِ همان روز را برمی‌دارد.
   - **لیست چک‌اوت** (`N1`…`N7`): همهٔ موارد **از اول منفی** حساب می‌شوند. هر کدام را که انجام دادی بزن تا
     منفی‌اش برداشته شود؛ نوار پیشرفت و شمارندهٔ «امتیاز منفی باقی‌مانده» زنده به‌روز می‌شود.
     آخرش **ثبت چک‌اوت** را بزن: هرچه پاک نشده باشد، به همان تعداد امتیاز منفی ثبت می‌شود و نوبت بسته می‌شود.
     (با «لغو چک‌اوت» همان نوبت و منفی‌هایش برمی‌گردد.)
3. **امتیازها**: کارنامهٔ **هر نفر در صفحهٔ خودش** — بدون جدول رقابتی. شامل آمار مثبت/منفی/چک‌این/چک‌اوت،
   درصد چک‌اوت کامل، نمودار تفکیک درصدی کارهای انجام‌شده، نمودار موارد جامانده، روند ۱۴ روز اخیر،
   جدول نوبت‌های حضور (از چک‌این تا چک‌اوت با کارهای همان نوبت) و ریز فعالیت‌ها.
4. **تاریخچه**: همهٔ ثبت‌ها با فیلتر شخص/نوع؛ هر ثبت قابل **ویرایش** (شخص، نوع، کار، تاریخ و ساعت، یادداشت) و **حذف** است.
5. **تنظیمات**: همگام‌سازی، خروجی اکسل، افراد، ویرایش کارها، پشتیبان‌گیری و پاک‌سازی.

## خروجی اکسل

دکمهٔ «خروجی اکسل» (بالای تبِ تاریخچه و در تنظیمات) یک فایل `.xlsx` با شش برگه می‌سازد:

| برگه | محتوا |
|---|---|
| تاریخچه | تک‌تک ثبت‌ها: ردیف، تاریخ، ساعت، روز هفته، نام، نوع، کد و عنوان کار، توضیح، امتیاز مثبت/منفی، یادداشت، ثبت‌کننده، شناسه |
| نوبت‌ها | هر نوبت از چک‌این تا چک‌اوت: مدت، امتیازها، کارهای انجام‌شده، موارد جامانده، وضعیت |
| خلاصهٔ افراد | جمع‌بندی هر نفر + درصد چک‌اوت کامل |
| روزانه | تفکیک روز به روز هر نفر (مناسب Pivot و نمودار) |
| آمار کارها | جدول کار × شخص |
| کارها | فهرست کارها با توضیح کامل |

ستون‌های عددی واقعاً عددند تا در اکسل جمع‌زدنی باشند، و برگه‌ها راست‌به‌چپ با سطر عنوان ثابت باز می‌شوند.
فایل بدون هیچ کتابخانه‌ای ساخته می‌شود (نوشتن مستقیم ZIP + SpreadsheetML)، پس آفلاین هم کار می‌کند.
اگر محیط اجازهٔ ذخیرهٔ `xlsx` ندهد، خودکار سراغ `csv` و در نهایت متن قابل‌کپی (Tab-separated) می‌رود.

## ظاهر

تم کاغذ کرم با جوهر قهوه‌ای؛ فونت‌ها **وزیرمتن** (متن) و **لاله‌زار** (تیترها) به‌صورت data-URI داخل خود فایل جاسازی شده‌اند،
پس بدون اینترنت و بدون CDN هم دقیقاً همین‌طور نمایش داده می‌شود. هر کار شکلک مخصوص خودش را دارد که از تنظیمات قابل تغییر است.

## کدها

برای اینکه لیست‌ها شلوغ نشوند، هر کار یک کد کوتاه دارد (`P1`, `N3`, `HOME`) و عنوانش خلاصه است.
با زدن ⓘ کنار هر کار، توضیح کامل باز می‌شود. کد و عنوان هر دو از بخش «تنظیمات» قابل ویرایش‌اند.

## پشتیبان و پاک کردن حافظه

- **دانلود فایل پشتیبان**: هر وقت بخواهی یک فایل JSON از کل اطلاعات می‌گیری.
- **بازیابی از فایل**: همان JSON را برمی‌گرداند.
- **پاک کردن ثبت‌ها** یا **ریست کامل**: پیش از حذف، فایل پشتیبان **به‌صورت خودکار دانلود می‌شود** و بعد حافظه پاک می‌گردد.

## همگام‌سازی بین گوشی‌ها

به‌صورت پیش‌فرض اطلاعات در `localStorage` **همان مرورگر و همان دستگاه** می‌ماند.
برای اینکه هر سه نفر از گوشی خودشان روی **یک لیست مشترک** ثبت کنند، اپ به یک Google Sheet وصل می‌شود:

- بک‌اند یک Google Apps Script است که روی شیت خودت اجرا می‌شود ([`google-apps-script/Code.gs`](google-apps-script/Code.gs)) — سرور واسطی در کار نیست.
- راه‌اندازی گام‌به‌گام (از انتشار سایت تا اشتراک با بقیه): [**SETUP.md**](SETUP.md)
- ثبت‌ها اول محلی ذخیره می‌شوند، بعد در پس‌زمینه بالا می‌روند؛ **آفلاین هم کار می‌کند** و بعد از وصل شدن خودش می‌فرستد.
- هر سطر یک `rev` سمت سرور می‌گیرد، پس ساعت اشتباهِ یک گوشی چیزی را خراب نمی‌کند؛ حذف‌ها هم به شکل tombstone منتقل می‌شوند و برنمی‌گردند.
- هر ثبت شناسهٔ نوبتش را با خود می‌برد، پس در شیت دقیقاً معلوم است به کدام چک‌این مربوط است.
- با «کپی لینک آماده برای بقیه»، گوشی بقیه با یک کلیک تنظیم می‌شود.
- برگه‌های شیت خودکار مرتب می‌شوند: شکستن متن داخل خانه (بدون سرریز)، عرض ستون بر اساس محتوا با سقف،
  سطر عنوان ثابت، رنگ‌بندی یک‌درمیان، و پنهان کردن ستون‌های فنی.

همگام‌سازی روی لینک claude.ai کار نمی‌کند (آن صفحه اجازهٔ اتصال بیرونی ندارد و خودش تذکر می‌دهد)؛ از لینک GitHub Pages استفاده کنید.

## تست‌ها

```bash
npm i --no-save playwright-core     # یک بار
node tests/run.js                   # همهٔ مجموعه‌ها
node tests/run.js sync              # فقط یکی
```

`tests/gas-emu.js` خودِ `Code.gs` را با شبیه‌سازی APIهای Apps Script اجرا می‌کند،
پس تست‌های همگام‌سازی روی بک‌اند واقعی اجرا می‌شوند نه روی یک بدل.
`sandbox.test.js` اپ را داخل iframe سندباکس‌شده — همان محدودیت نمایشگر آرتیفکت — اجرا می‌کند.

## انتشار روی GitHub Pages

`Settings → Pages` → شاخهٔ `main` و پوشهٔ `/ (root)`.
مراحل کامل با تمام کلیک‌ها در [SETUP.md](SETUP.md) آمده است.
